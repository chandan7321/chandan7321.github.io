## 📚 Introduction
Jarida (Jadx + Frida) is a user-friendly tool that enhances your experience with Jadx, a popular decompiler. This plugin allows you to trace and optionally change Java method return values while you work. You can do all of this right from the decompiled view of your Android applications. 

## ⚙️ Features
- **Runtime Tracing**: Track the execution flow of Java methods easily.
- **Patching Capabilities**: Modify return values in real-time to test changes.
- **Seamless Integration**: Works directly within the Jadx GUI, making it simple to use.
- **Mobile Focused**: Designed primarily for reverse-engineering Android applications but usable in various Java environments.

## ✅ System Requirements
Before you download Jarida, ensure your system meets the following requirements:
- **Operating System**: Windows, macOS, or Linux.
- **Java Version**: You need JDK 8 or higher installed.
- **Jadx Version**: Make sure you are using the latest version of Jadx.

## 🚀 Getting Started
To start using Jarida, follow these steps:

1. **Visit the Releases Page**
   Go to the [Releases page](https://github.com/chandan7321/Jarida/releases) to find the latest version of Jarida.

2. **Download the Plugin**
   Find the latest version and click on the link to download the Jarida plugin file. This file is usually a zipped folder containing the necessary components.

3. **Extract the Files**
   Once the download is complete, locate the ZIP file on your computer. Right-click and select "Extract All" to extract the contents into a folder.

4. **Open Jadx**
   Launch the Jadx application on your computer to get started. If you have not installed Jadx yet, you can download it from [Jadx GitHub page](https://github.com/skylot/jadx/releases).

5. **Install the Jarida Plugin**
   - Navigate to the "Plugins" folder in the extracted Jarida files.
   - Copy the contents of this folder to the "Plugins" folder in your Jadx installation directory. If you don't see a "Plugins" folder in Jadx, create one.

6. **Restart Jadx**
   Close the Jadx application and open it again. This step ensures that the newly added Jarida plugin is properly recognized.

7. **Using Jarida**
   With Jadx open, you can now navigate through your decompiled APK. When you locate a Java method, you’ll see new options added by Jarida that allow you to trace and modify return values directly from the user interface.
